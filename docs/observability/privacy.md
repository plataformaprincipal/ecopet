# Privacidade

Dados enviados: metadados técnicos (rota, status, duração, hashes, erros sanitizados).

Proibido: senhas, tokens, cookies, SQL com valores, prompts/respostas IA completas, mensagens TalkJS, cartão, CPF completo, e-mail completo em logs gerais (mascarar quando necessário).

Retenção: conforme plano Better Stack (configurar no painel).

Não afirmar conformidade LGPD integral sem revisão jurídica.
