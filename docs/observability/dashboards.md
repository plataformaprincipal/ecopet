# Dashboards (manuais)

No Better Stack, criar painéis filtrando por `module` / `event` / `metricName`:

1. Aplicação — requests, erros, latência  
2. Integrações — openai, talkjs, mercado_pago, firebase, resend, cloudinary  
3. Banco — prisma (quando `OBS_FLAG_DB_TRACING`)  
4. IA — tokens, duração, erros  
5. Mensagens — webhooks TalkJS  
6. Segurança — `security.*`  
7. Negócio — eventos de domínio (quando emitidos)

Não há provisionamento automático via API nesta versão.
