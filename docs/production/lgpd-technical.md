# LGPD — base técnica (não jurídica)

Capacidades técnicas esperadas / auditar:

- Preferências de notificação  
- Consentimento analytics (Consent Mode)  
- Redaction em logs  
- Exportação / exclusão de conta (verificar rotas privacy)  
- Minimização em IA (sem prontuário/prompts completos nos logs)  

**Não afirmar conformidade jurídica.** Revisar com advogado: bases legais, DPA com subprocessadores (OpenAI, TalkJS, MP, Firebase, Resend, Cloudinary, Better Stack, Supabase, Vercel, Google).
