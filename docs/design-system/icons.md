# Iconografia

## Biblioteca padrão

**lucide-react** (já instalada). Não adicionar outra lib.

## Padrões

| Contexto | Tamanho | Stroke |
|----------|---------|--------|
| Navegação | 20px (`h-5 w-5`) | 2 |
| Botão | 18–20px | 2 |
| Status / inline | 16px | 2 |
| Destaque | 24–32px | 2 |

## Regras

- Preferir outline consistente
- Não misturar filled/outline sem regra
- Não usar emojis como ícone de interface
- Alinhar com `items-center` e gap consistente
- Referência TS: `apps/web/src/lib/design-system/tokens.ts` → `iconography`
