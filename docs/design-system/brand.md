# Marca EcoPet

## Componentes

- `BrandMark` — símbolo SVG
- `EcoPetLogo` — símbolo + wordmark (horizontal / vertical / icon / dark / light)
- `InstitutionalLoader` — loading de marca
- Assets em `apps/web/public/brand/`

## Variações de arquivo

| Arquivo | Uso |
|---------|-----|
| `ecopet-mark.svg` | Favicon / símbolo |
| `ecopet-horizontal.svg` | Lockup horizontal |
| `ecopet-vertical.svg` | Lockup vertical |
| `ecopet-wordmark-light.svg` | Wordmark branco |
| `ecopet-wordmark-dark.svg` | Wordmark escuro |
| `ecopet-icon-192.svg` / `512` | PWA |
| `ecopet-logo.png` | Legacy / OG fallback |

## Wordmark

- Nome: **EcoPet**
- Em fundo verde/escuro: `#FFFFFF` puro
- Nunca cream/acinzentado no nome da marca

## Direção do símbolo

Abstração de ecossistema: anel + nós (conexão/IA) + pétala (cuidado/natureza). Escalável e não infantil.
